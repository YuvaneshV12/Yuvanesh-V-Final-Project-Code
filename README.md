# 🍎 Fruit Shop Landing Page

A responsive and visually appealing fruit shop landing page showcasing a variety of organic apples grown in the scenic valley of Kashmir.

## 🌐 Live Preview

👉 [Live Demo](https://fruit-shop-landing.vercel.app)

## 📋 Features

* Sticky navigation bar with smooth scrolling
* Eye-catching hero section
* Informative "About Us" section
* Showcase of multiple apple varieties
* Clear service highlights
* Embedded YouTube video showing apple benefits
* Responsive design for all screen sizes
* Contact form for inquiries or orders

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/YuvaneshV12/fruit-shop-landing-page.git
```

Open the project folder in your preferred editor and open `index.html` in your browser.
